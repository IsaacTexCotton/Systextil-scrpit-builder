# Política de segurança

A segurança operacional do Systextil e a proteção de dados de clientes têm prioridade.

## O que não deve ser publicado

Não abra uma issue pública contendo:
- senhas, tokens, cookies ou cabeçalhos de autenticação;
- CNPJ associado a dados de contato, nomes ou dados de clientes;
- títulos, boletos, valores, saldos, dados bancários ou payloads do ERP;
- URLs com parâmetros de sessão ou identificadores sensíveis;
- arquivos HAR, traces ou screenshots não sanitizados.

## Reportar vulnerabilidade

Não descreva uma vulnerabilidade explorável em issue pública ou Pull Request.

Quando o recurso de Private vulnerability reporting / Security Advisories estiver habilitado neste repositório, utilize o canal privado do GitHub. Se não estiver disponível, entre em contato com o mantenedor pelo perfil GitHub antes de divulgar publicamente.

Não há endereço de e-mail de segurança definido neste repositório.

## Tratamento

Ao reportar, forneça a descrição mínima necessária, impacto, pré-condições e uma forma segura de reproduzir usando dados fictícios. Não acesse, altere ou extraia dados de terceiros para demonstrar um problema.

## Limites

Esta política não representa garantia de prazo de resposta ou de suporte a versões específicas. O mantenedor deverá definir esses compromissos quando o projeto tiver uma versão de produção.
